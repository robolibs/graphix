  Broad development entrypoint.
- `spatial_pathfinding`
  Point set -> graph -> route.
- `spatial_pose_graph`
  Point set -> graph -> route -> pose graph -> optimization.
- `robust_slam`
  SE2 optimization with robust losses.
- `compare_optimizers`
  Compare optimizer behavior on the same SE2 problem.
